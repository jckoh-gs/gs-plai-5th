# 제품1.4.0 미디어 호환성 준비

IDEA-008 채택 문서 af8253f를 기준으로 한 준비 검토다. 실제 배포/stable1.3을 바꾸거나1.4 구현·배포 인수 성공을 주장하지 않는다. 최종 영상은 원래 동결 창 이후 확정한 배포에서 새로 제작한다.

- final-deck-binding은 기존1.0~1.3 지원을 유지하고 정확히1.4.0만 추가 허용한다.1.4.1/1.4.0-rc.1/1.5.0/2.0.0은 모든 fixture 버전을 일치시켜도 거절한다.
-1.4.0/PRD1.11 fixture는 run/deployment/manifest/facts/command export를 모두 일치시켜 통과했다. 기존 보안·시간·동일영상·복구 증거 제한은 유지한다. 관련 전체36시험 통과.
- release-features의 기존 규칙은1.4.0에서 preview=true/commandExport=true를 반환한다. 새 기능을 자동 영상 장면으로 추론하지 않으므로 변경할 필요가 없다.
- 기존8장면은 명령 입력 폼의 범위/날짜 오류를 제출하지 않는다.125kW 명령은 별도 MQTT 클라이언트다. 목표값·처리 결과 탭은 내보내기/상태 확인용이며 새 일반 REST 목표 폼 검증을 시연했다고 표현하면 안 된다.
- facts.template.json은1.3 사전 준비용 그대로 보존했다. 최종1.4 채택 시 제품/PRD 버전과 실제 증거 해시를 갱신하고 개선 슬라이드에 IDEA-008을 **별도 인수 근거로 검증한 개선**으로만 적는다. 후보 구현/검증/배포가 아직 없으면 완료 문구를 쓰지 않는다.
- 시연에서 새 입력 안내를 반드시 보여주려면 범위 밖 값의 전송 차단·날짜 오류·수정 후 재제출을 별도 실제 UI 조작으로 추가하고 검증해야 한다. 현재 승인된 미디어 흐름에는 없으므로 이번 준비에서는 장면을 추가하지 않았다. 기존1.3으로 복원하면 해당 개선 문구를 포함하지 않는다.

수정은 binder의 버전 허용 조건과 fixture 시험뿐이다. 앱·배포·원본 시간·PRD·최종 미디어·기존 검증 기록은 변경하지 않았다.
