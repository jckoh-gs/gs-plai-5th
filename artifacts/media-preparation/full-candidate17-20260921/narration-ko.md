## 1. VPP 시험 목적과 시스템 경계

이 영상은 제작 과정을 확인하는 리허설입니다. 로컬 가상 데이터로 실제 화면을 조작합니다. GRID는 외부 VPP의 데이터 수집과 제어 경로를 시험하며 실물 설비나 시장 입찰은 다루지 않습니다.

## 2. CSV 등록과 가상 현장

CSV 또는 TSV를 넣고 해석 미리보기로 시각과 단위, 정규화 출력을 먼저 확인합니다. 미리보기는 RTU를 만들지 않습니다. 실제 등록 때 다시 검증하고 일 초 단위 수집을 시작합니다. 원본 전류와 추정 전류도 구분합니다.

## 3. 풍력 태양광 복합 UI

풍력과 태양광, 복합 단지를 같은 대시보드에서 선택합니다. 삼차원 장면에서 풍향과 회전을 확인하고 드래그와 휠로 시점을 조절합니다. 계측값은 현재 선택한 단지와 발전기 상태를 보여줍니다. 명령 접수는 완료와 다릅니다. 접수 패널은 마지막 관측값이며 저장 상태 확인으로 서버 상태를 다시 조회합니다.

## 4. RTU와 전체 SCADA 데이터

각 RTU는 연결과 건강 상태를 독립적으로 관리합니다. 전체 발전기의 샘플을 수집하고 기본 육십 초마다 MQTT로 전송합니다. 큐오에스 일은 전달 과정의 중복 가능성이 있으므로 메시지 식별자로 중복을 처리합니다.

## 5. 외부 VPP 목표 출력 제어

별도 MQTT 클라이언트로 백이십오 킬로와트를 요청합니다. 수락과 실행을 거쳐 실제 출력이 목표에 도달하면 완료 상태를 받습니다. 화면의 MQTT 출처와 목표 및 실제 값을 확인합니다. 이 결과는 실제 로컬 브로커에서 관측한 값입니다. 목록의 마지막 확인 시각은 브라우저 조회 시각이며 명령 완료 시각과 다릅니다. 최근 저장 상태를 최대 스무 개까지 JSON으로 내보냅니다. 이 파일은 외부 VPP 수신 증거나 전체 감사 이력이 아닙니다.

## 6. 장애 주입과 복구

통신 단절과 지연, 센서 중지를 구분해 시험합니다. 센서가 멈춘 구간은 결측으로 남습니다. 미확인 배치의 재시작 복구는 함께 제공하는 별도 실행 근거에서 확인할 수 있습니다.

## 7. 재현 가능한 시나리오와 연동

배속과 일시정지, 난수 시드로 시험 조건을 조절합니다. 선택한 RTU의 시나리오를 복원하면 새 실행 식별자가 생깁니다. 이전 실행은 런 아이디로 구분하며 기존 아웃박스를 삭제하지 않습니다. 가이드에서 이 RTU의 토픽과 규격을 확인합니다.

## 8. 검증 범위와 남은 제약

이 리허설은 로컬 동작과 제작 도구를 확인했습니다. 최종 영상은 동결한 케이쓰리에스 버전으로 새로 녹화합니다. 최종 발표자료와 영상은 같은 릴리스 증거를 사용하며 실제 외부 VPP와 클라우드 미검증 범위를 명시합니다.
