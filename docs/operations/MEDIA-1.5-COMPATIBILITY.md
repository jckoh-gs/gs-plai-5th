# 제품1.5 후보 미디어 호환성 준비

채택 b9c10ae / IDEA-009 / PRD1.12의 준비 검토다. 현재 안정1.4용 facts.template.json은 유지했다. 이 문서는1.5 구현·배포·인수 완료 또는 최종 미디어 완성을 뜻하지 않는다. 최종 영상과 PPT의 권위는 동결 시 실제 선택한 매니페스트와 새 실행 근거다.

final-deck-binding은 기존 지원과 정확한1.4.0 복원 경로를 유지하고 정확한1.5.0만 추가 허용한다. 모든 fixture의 run/deployment/manifest/facts/내보내기 버전이 일치한1.5.0/PRD1.12 정상 경로와1.4.0/PRD1.11 복원 경로를 확인했다.1.5.1,1.5.0-rc.1,1.6.0 및 미검토 다른 버전은 거절한다. 변경된 허용 조건의 관련 바인더 시험39개를 한 번 실행해 통과했다. 전체 제품 시험·녹화·렌더는 수행하지 않았다.

기존8장면은 대시보드 set_limit/start/stop을 실행하므로1.5 배포에서 촬영하면 새로운 REST 접수 표시가 실제 화면에 나타날 수 있다. 그러나 일반 Target 폼 제출, 개별 발전기 제어, 응답 유실·재시도·실패 안내를 별도 시연하는 장면은 없다. UI 구현 이후 실제 촬영에서 보이는 접수 표시만 소개하고, 촬영하지 않은 경로는 별도 인수 근거로 구분한다. 기능 채택만으로 장면을 자동 추가하지 않는다. 새 receipt의 위치나 대기/비활성 표시가 기존 버튼 선택자·화면 높이에 미치는 영향은 최종 실제 UI를 확인해야 하며 이번 바인더 버전 시험으로 UI까지 통과했다고 판단하지 않는다.

125kW 장면은 계속 별도 MQTT 클라이언트다. REST receipt의 accepted는 접수, executing은 전달, completed는 실제 출력 피드백 완료다. 접수 메시지 또는 알림만으로 제어 성공·MQTT 완료·운영 VPP 수신을 주장하지 않는다. 영상의125/오차0과 상태 전이는 최종 별도 MQTT 보고서로 확인한다. 응답을 받지 못한 경우 실제 처리 여부가 미확인이라는 기능 설명도 실제 화면 또는 별도 검증 근거가 있을 때만 사용한다.

1.5가 안정 버전으로 승격되어 최종 선택되면 facts 복사본의 제품/PRD 버전과 정확한 증거를 갱신한다. 개선 슬라이드에는 “REST 명령의 대상·명령 ID·접수 상태 안내”를 추가할 수 있으나 “모든 오류 경로를 영상에서 시연했다”는 문구는 넣지 않는다.1.4로 복원되면1.5 문구를 제외한다. 최종 녹화는 원래 동결 이후이며 기존 시간·해시·복구·비밀 제외·영상 우선 조건은 유지한다.

## 00ad4e6 보정 리허설 이후 발표자료 준비 검토

이 절은 앞의 후보 검토 이후 수행한 준비 결과다. 실제 최종 영상이나 청취 검수 완료를 뜻하지 않는다. `artifacts/checkpoints/media-candidate15-receipts/`의 검증·복원·MQTT·내보내기·8개 인코딩 프레임과 추가 접수 프레임을 근거로 한다. 로컬3109는 메인이 정상 종료했으며 이 검토에서는 접근하거나 다시 시작하지 않았다.

최신8장면 리허설은249.33초, 제작272.706초다. 세 번째 장면의 계획 시간이28초에서36초로 늘었고, 마지막 set_limit100 이후 저장 상태 조회를 한 번 수행해 completed를 실제로 표시했다. 이 동작은 정확한1.5.0에서만 생성되며1.4 복원 경로에는 없다. 네 번째 RTU 지표 장면의 중앙 확대를 제거해 양쪽 값이 보이고 CSV 확대와 실제3D 조작은 유지된다. 시각 근거는 `review-scene-4.png`, `review-receipt.png`와 `source/rest-receipt-stored-status.png`다.

발표자료 바인더는 고정 시간표가 아니라 실제 최종 `scenes.json`의 start/end+lead를 사용한다. 따라서 세 번째 장면의8초 증가는 이후 슬라이드 타임코드에 자동 반영된다.249.33초나 리허설 timecode를 최종 facts에 복사하지 않는다. 현재14장 구성과 sceneIndex0~7은 그대로 유효하고 추가 렌더는 필요하지 않다.

승격 전 `facts.template.json`의 제품1.4.0/PRD1.11 및 과거 증거 경로는 유지한다. 공통 슬라이드7 설명에는 정지 조작 후 기동으로 대체된 명령을 정지 완료로 주장하지 않는 문장을 추가했다. 이후 메인의1.5 안정 승격 메시지를 받으면 다음 내용만 검토하여 반영한다.

- 슬라이드6: 기존 accepted/executing/completed 의미와 별도 MQTT125kW 검증을 유지한다. “대시보드의 REST 접수 패널은 마지막 관측 상태입니다. 저장 상태 확인은 서버에 저장된 상태를 다시 읽습니다. 접수 안내만으로 완료를 판단하지 않습니다.”를 설명에 추가한다. 일반 Target 폼은 제출하지 않았다는 제한은 유지한다.
- 슬라이드7: “상한 명령 후 접수 확인에서 대상 RTU와 명령 ID를 확인하고 저장 상태를 조회합니다. 앞선 정지는 뒤의 기동에 의해 대체될 수 있으며 모든 조작을 완료로 표현하지 않습니다.”를 설명에 추가한다. 영상의 새 접수 장면을 직접 보여주려면 해당 슬라이드 캡처를 `rest-receipt-stored-status.png`로 선택하고 실제 최종 캡처 해시를 검수한다. 본문은 삼차원 선택과 명령 확인을 함께 소개한다. 실제3D 화면은 같은 영상의 hybrid-camera 원본으로 보존한다.
- 슬라이드14: “1.5는 REST 명령의 대상·명령 ID·마지막 관측 상태와 저장 상태 재조회 안내를 추가했습니다. 접수와 실행 완료를 구분합니다.”를 개선 이력에 추가한다. 응답 유실·중복·모든 오류 경로를 영상으로 시연했다고 적지 않는다.
- 슬라이드6/9/11/14의 manifestEvidence는 승격된 매니페스트에 실제 포함된 경로와 해시로 다시 선택한다. 현재1.4의 fdd0491 경로를1.5의 현재 배포·백업 증거로 재명명하거나 추정하지 않는다. 정확한1.5 증거를 확인하지 못하면 준비 상태를 유지한다.

별도MQTT 명령은 accepted→executing→completed, 실제125kW/오차0을 관측했다. REST 정지 행은 superseded이므로 완료된 정지 시연이라는 주장은 금지한다.31개 자막은 원고·타이밍과 일치했고 전체 디코딩과 -19.3dB 신호 확인을 수행했다. 음성 발음과 의미를 실제 청취했다고 기록하지 않는다. 최종에서는 새 영상·명령 보고서·복원 기록·캡처를 다시 검수해야 한다.

이번 후속 변경은 준비 문서와 공통 설명 문장뿐이다. JSON 파싱과14장/미검수 보호값 유지, 실제 바인더 시간 계산식을 읽어 확인했다. 실행 소스·선택자·바인더 계산은 변경하지 않았으므로39개 회귀검사나 전체 녹화·PPT 렌더를 반복하지 않았다.

## 기능 안정1.5 승격 후 템플릿 갱신

메인의 기능 안정 승격 통지를 받은 뒤 `facts.template.json`의 준비 선택을 제품1.5.0/PRD1.12로 갱신했다. reviewed:false/preparationTemplate:true와 모든 실제 최종 영상·캡처 해시 자리표시는 유지한다. 슬라이드6/7/14의 REST 마지막 관측·저장 상태 재조회·접수와 완료 구분, 정지 대체 설명을 반영했고 슬라이드7은 실제 최종 `rest-receipt-stored-status.png`를 사용할 예정이다. 세 번째 장면 시간 증가는 실제 최종 타임라인으로 연결한다.

증거 후보는 현재 실제 존재하는 `candidate-6d165d1/restored-command-form/result.json`, `restored-command-receipts-round2/result.json`, `outbox-restart.json`, `restore-summary.json`과 `stable-backup-6d165d1.json`으로 갱신했다. 각 결과 PASS 및 복원 제품1.5/하위호환1.4 범위를 읽어 확인했다. 최종 선택 매니페스트에 해당 경로·해시가 정확히 포함되는지는 바인더가 다시 확인한다. 아직 작성 중인 매니페스트를 이미 확정된 최종 근거로 간주하지 않는다. 구조 검사에서14장·장면 인덱스·모든 공개 출처 경로·정확한1.5 접수 기능 분기·미검수 보호값을 확인했다. 추가 녹화·렌더·청취 또는 원격 조작은 수행하지 않았다.
