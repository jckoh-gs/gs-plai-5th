제품 1.1.0 / PRD 1.8 / 런타임 소스 `8599ab92af7f884871b7f7f89a0baf3b253d300a`. IDEA-005의 CSV 등록 전 미리보기를 구현했다. 단위·시간대·보간·출력 범위와 앞 3행을 확인하며 RTU를 만들지 않는다. 늦은 응답·파일 읽기 경합, 20MiB·100000행·128열 한도, CSV/JSON 오류 원문 비노출을 검증했다.

실행 이미지 `sha256:07f968cc6e5a11d31c9a1f2d55b287c19cac7f11574925b58004745dae396420`에서 단위시험 71개 및 실제 MQTT 통합·장애 시험이 통과했다. 원격 인증 UI/SSE/미리보기/경합/좁은 화면, 실제125kW·오차0·60개 샘플·중복제거를 확인했다. 실제 Pod 교체 후 미전송 메시지의 ID·순서·본문 보존과 MQTT 재수신/PUBACK도 통과했다. 증거는 `deploy/verification/candidate-8599ab9/`에 보관한다.

백업 `deploy/verification/stable-backup-8599ab9.json`은 105144320바이트이며 SHA256은 `29071fdc6a800e7b173aeaa49c45a6f4f83b0dacbaf5e6594f1ea66864c21879`다. 이 정확한 스냅샷을 새 격리 PVC로 복원하여 5단지의 원래 실행/발전기 ID·데이터 행 수·시나리오, UI, 미리보기, 실제 MQTT를 검증했다. 같은 DB를 이전 안정 버전1.0.0에서도 실행해 원본 데이터·UI·MQTT 호환성을 확인했다. 복구 배포는0개이며 PVC와 백업을 보존한다.

대용량 백업은 원격 gzip·해시와 로컬 압축 해제·해시를 streaming 처리한다. 고정 크기 청크의 길이·해시와 전체 파일 해시·SQLite 무결성을 확인한 뒤 로컬 파일을 승격한다. 실제 Ready Pod·UID·이미지 digest를 검증하며 부분 파일을 정상 백업으로 표시하지 않는다. 105MB 동일 스냅샷 재전송도 통과했다. 실제 OOM을 경험한 것은 아니며 장시간 DB 증가에 대비한 예방 보강이다.

태그 `stable-runtime-v1.1.0-8599ab9`와 `artifacts/releases/checkpoint-1.1.0.json`을 사용한다. 이전 체크포인트1.0.0의 태그·매니페스트·백업은 유지한다. 이미지 검사 잔여 항목은 앱4, broker10이며 현재 수정 버전이 없는 항목별 관리 문서를 유지한다. 전체14시간 목표는 진행 중이며 최종30분 영상→PPT 제작·검수는 아직 완료하지 않았다.
