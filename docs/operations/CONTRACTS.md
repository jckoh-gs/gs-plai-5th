# Greenfield integration contract

Only this project is the implementation source. Do not inspect/copy the sibling legacy project. Read PRD v1.5 and GOAL v1.3; latest user authorizes greenfield development and mandatory k3s deployment. Run times in run.json override old PRD OPS-01. Owner main handles package/lock, API/index, deployment, integration and release. Model agent owns server/model.js, server/weather.js, tests/model*.test.js, tests/weather*.test.js. Transport agent owns server/store.js, server/control.js, server/transport.js, server/metrics.js and their unit tests. UI agent owns web/**. Shared changes require coordination.

## Model module exports (synchronous, plain serializable data)
`parseCSV(text,{type='wind',unit='kw',semantics='sample'}={})` returns normalized dataset `{rows:[{timestamp:ISO,power_kw,...}],unit,semantics,interpolation}`. `parseIrradianceCSV(text)` separate dataset.
`createPlant(input)` validates registration, generates UUID plant id/runId and full mutable plant. Plant has name/type/lat/lon/station, dataset, generators, replay `{speed,paused,seed,noisePct,freezeLiveWeather}`, simulationSeconds, seconds (CSV offset), rngState/faultRngState, mode='csv', weather `{wind_speed_ms,wind_direction_deg,irradiance_wm2,temperature}`, weatherSource/weatherObservedAt/weatherError, irradianceDataset, faults, history.
`stepPlant(plant, now=Date.now())` mutates one virtual second, returning complete SCADA frame (before/after step timestamp semantics documented by model). `snapshotPlant(plant,now)` returns frame without stepping. `publicPlant(plant)` returns API plant (dataset rows may be omitted but metadata/count included). `updateGenerator(plant,id,patch)`, `updateReplay(plant,patch)`, `updateWeather(plant,patch)`, `updateFaults(plant,patch)` validate atomically then mutate. Main cancels active commands on model edits.
Generators and frames follow PRD naming exactly (camelCase generator fields, snake_case weather). Model state has generator targetLimitKw nullable, targetKw, availableKw, powerKw. All error objects have message; API converts to 400.
Weather: `refreshWeather(plant,{explicit=false,authKey=process.env.KMA_AUTH_KEY,fetchImpl=fetch,now=Date.now()}={})` async preserves valid previous values on failure and respects manual/freezeLiveWeather. Export pure parser for fixture tests.

## Runtime contract
`Store(path)` synchronous node:sqlite; `.loadPlants()` array, `.savePlant(p)`, `.transaction(fn)`, `.addFrame(p,frame)`, `.enqueue(plantId,topicSuffix,body)` outbox UUID/seq envelope, `.batch(plantId)` size-limited telemetry; `.pending(plantId)` earliest outbox or null with `{id,topic,body,seq}` body serialized JSON; `.attempt(id)`, `.ack(id)`, `.queueStats(plantId)`; `.loadCommands()` array, `.saveCommand(c)`, `.commandEvent(c)`; `.loadMetrics(id)`, `.saveMetrics(id,m)`; `.audit(level,message)`, `.events(limit=80)`, `.samples(id,limit=3600)`, `.frames(id,limit=120)`, `.scenarios()`, `.saveScenario(s)`, `.getScenario(id)`, `.prune(days)`, `.close()`. Agent may add helpers; communicate changes immediately.
`Controller(store, plantsMap, {onEvent}={})`: `.submit(plantId,request,source='REST',options={retained:false,setpoint:false})` returns persisted status; `.tick(now=Date.now())` progresses commands; `.cancelPlant(id,reason)`; `.list(id)` recent commands. Command state+model+outbox atomic.
`Transport(store,controller,plantsMap,{url,prefix,telemetrySeconds,...}={})`: `.start()`, `.sync()` ensure current plants and offline flags, `.stop()` async, `.metrics(id)` RTU metrics including health, clientId, connection and queue stats; `.gateway()` gateway status. Transport manages 100ms send pump and 60s batches. Collect counter `.collected(id,frame)` called by main after frame transaction. Counters persist; no invented device hardware.

## HTTP/UI contract
API paths exactly PRD 16. GET /api/state and SSE /api/events data return `{version,contractVersion:2,plants:[public plant + {metrics}],gateway,events}`. SSE uses default message event. Health unauthenticated only. UI receives auth by user token login (sessionStorage) and uses fetch-stream SSE with Authorization to support remote auth. UI optional token prompt should only appear after 401. GET /api/config public returns `{authRequired,version}` without secrets. API responses: GET arrays directly except state; mutations return updated plant or command/scenario object. Errors `{error:string}` status 400/404/401. POST /api/plants expects PRD registration. PATCH weather accepts `{mode,...snake_case weather fields}`; replay top-level fields. scenarios POST `{plantId,name}`; run POST no body; export JSON. Guide downloaded /api/guide. Samples GET /samples/wind.csv etc. UI must use server live state, no mock success data.
