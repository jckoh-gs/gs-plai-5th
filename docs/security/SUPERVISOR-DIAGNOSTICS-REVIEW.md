# Supervisor diagnostic review

Independent source review and isolated fixture run: 27 passed, zero failed. Source hashes and test output are preserved in `evidence/supervisor-diagnostics-independent-review.json` and `evidence/supervisor-diagnostics-independent-tests.log`. No running supervisor, observer, tunnel, or remote deployment was changed.

No blocking disclosure defect found in the reviewed delta. Diagnostics persist fixed result/phase/kind values, numeric HTTP status, monotonic duration, and checkedAt. HTTP bodies, credential paths, token contents, request headers, raw errors and URLs are not copied into diagnostics. Unknown error codes and diagnosticKind strings become request_failed. HTTP body transport failure remains distinct from JSON syntax failure. Independent adversarial fixtures cover hostile error metadata, JSON null/arrays/string/object values, non-2xx bodies never parsed, and preservation of the previous local-check timestamp on a later remote failure. Existing fixtures cover token-file failures, timeout, connection refusal, response reset, event deduplication, owned-forward recovery, external-forward preservation, freeze and deadline behavior.

`lastLocalVerification` means the last completed local probe, not a new local check at each published remote failure. Its checkedAt can precede the status timestamp. broker_disconnected means the API reported connected !== true; connection_reset/closed/refused are observed transport outcomes, not established root causes. mqtt_tcp currently records only tcp_unreachable rather than claiming a more specific TCP cause. No conclusion about the historical 12:58/13:03 incident follows from these newly added categories.

The boolean verifyLocal API and retry/teardown policy remain intact. Two minor validation differences are explicit: connected now requires boolean true instead of any truthy value, and invalid health stops before requesting config. These match the current server contract but are not byte-for-byte identical request behavior on malformed responses. Repeated equivalent failures remain deduplicated; phase/kind/httpStatus changes emit a new event, while checkedAt/duration alone do not.

Scope limitations: existing response JSON parsing is not newly size-bounded by this patch; the probe targets the trusted local forwarded application. Diagnostics do not establish server-side causality or recover missed historical evidence. This review is a source/isolated-test gate, not evidence that the running supervisor was replaced.
